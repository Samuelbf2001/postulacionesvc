## 🚀 FLUJO RÁPIDO (2 HORAS)

### Paso 1: Prepara contexto (10 min)
```
Abre tu mente mental:
✓ ¿A quién envío? (Angel, VC, PE, Corporate?)
✓ ¿Cuándo? (fecha de envío)
✓ ¿Cuánto pido? (monto USD)
✓ ¿Cuál es el fondo? (nombre, website)
```

### Paso 2: Selecciona plantilla (5 min)
```
Si tienes 10 minutos o menos con el inversor:
→ PLANTILLA-EXECUTIVE-SUMMARY.md

Si tienes 30+ minutos o es primera reunión:
→ PLANTILLA-PROPUESTA-INVERSION-BASE.md

Si no sabes qué énfasis darle:
→ PLANTILLA-POR-TIPO-DE-INVERSOR.md (busca tu tipo)
```

### Paso 3: Copia y reemplaza (30 min)
```
Abre la plantilla en Google Docs / Word

Busca y reemplaza:
[FECHA] → 2026-07-12
[MONTO] → USD 1,500,000 (ejemplo)
[FONDO] → Nombre del fondo
[PAÍS/REGIÓN] → Colombia / Latam

Ajusta números de traction:
- Proyectos: 50+
- Sectores: 15+
- Satisfacción: 98%
- Clientes operativos: [TU NÚMERO ACTUAL]
```

### Paso 4: Valida con checklist (30 min)
```
Abre: 4-checklists/CHECKLIST-PROPUESTA-INVERSION.md

Marca cada sección:
✓ Estructura y completitud
✓ Contenido — Problema
✓ Contenido — Solución
✓ Contenido — Traction
✓ Contenido — Mercado
✓ Contenido — Modelo de Negocio
✓ Contenido — Financiero
✓ Contenido — Equipo
✓ Contenido — Uso de Fondos
✓ Contenido — Riesgos
✓ Contenido — Anexos
✓ Tono y lenguaje
✓ Adaptación a inversor
✓ Formato y presentación
✓ Últimas validaciones

Si alguno está incompleto → vuelve a plantilla y completa
```

### Paso 5: Revisa finales (15 min)
```
□ Números son consistentes en todo documento
□ Sin faltas de ortografía
□ Links funcionan
□ Formato es profesional (márgenes, fuente)
□ Metadata del PDF dice "Confidential"
□ Archivo está bien nombrado: PROPUESTA-SIXTEAM-[FONDO]-[FECHA]-v01.pdf
```

## 🚨 ERRORES COMUNES (EVITA)

❌ **Error 1: Números inconsistentes**
```
Sección 5 dice: "50 proyectos"
Sección 8 dice: "60 proyectos"
→ REVISAR ANTES DE ENVIAR
```

❌ **Error 2: Proposición genérica**
```
Mala: "Transformamos negocios con tecnología"
Buena: "Reemplazamos 5-10 proveedores con 1 equipo centralizado. Land-and-expand desde $199/mes."
```

❌ **Error 3: Omitir números reales**
```
Mala: "Muchas empresas tienen problema..."
Buena: "2.5M de SMBs en Latam gastan $5K-20K/mes coordinando 5-10 proveedores diferentes"
```

❌ **Error 4: No adaptar a inversor**
```
Mala: Mismo pitch para Angel, VC, PE
Buena: Angel ve retorno esperado, VC ve escalabilidad, PE ve EBITDA
```

❌ **Error 5: Sin follow-up**
```
Mala: Envías propuesta y esperas
Buena: Envías + haces follow-up en 7 días
```

## 🎁 BONUS: PREGUNTAS QUE TE VAN A HACER

Prepárate para estas (las hace todo inversor):

### Ángel pregunta:
> **"¿Si todo sale perfecto, cuándo veo 10x?"**
RESPUESTA: "Si alcanzamos $X MRR en Año 2, valúa sube a $X, 10x en 2-3 años es realista. Conservador: 5-7x."

### VC pregunta:
> **"¿Quién es tu competencia y por qué ganas?"**
RESPUESTA: "Velocity, Atomic son implementadores puntuales. Nosotros somos equipo permanente recurrente. Plus: español para Latam, CAC bajo (boca a boca)."

### PE pregunta:
> **"¿Cuál es tu EBITDA a escala?"**
RESPUESTA: "Gross margin 70%, target EBITDA 35% en Año 3. Operación lean, equipo remoto, predecible."

### Corporate pregunta:
> **"¿Cómo nos ayudas a crecer?"**
RESPUESTA: "Ustedes venden plataforma, nosotros la operamos. Juntos reducimos churn de su CRM, aumentamos upsell, TAM crece."
