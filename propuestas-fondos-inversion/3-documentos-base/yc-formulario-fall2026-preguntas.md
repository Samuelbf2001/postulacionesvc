## LO QUE FALTA PARA PODER ENVIAR

### Datos que solo tú tienes
- [ ] MRR actual en número exacto
- [ ] Volumen de operación de los agentes (conversaciones/mes u operaciones/mes)
- [ ] Fecha en que cada founder empezó y fecha en que pasó a full-time
- [ ] Entidad legal: país, tipo, % de cada founder
- [ ] ¿Inversión recibida? ¿Fundraising activo?
- [ ] ¿Aplicación previa a YC? ¿Aceleradora previa?
- [ ] Ciudad actual + decisión de dónde queda la empresa después del batch
- [ ] Unit economics confirmados (margen bruto, churn, expansión)
- [ ] ¿Ernesto toca código/automatizaciones directamente? ¿Algún freelancer tocó producto?
- [ ] Cómo escuchaste de YC (respuesta real, no genérica)

### Archivos que hay que producir
- [ ] Founder video — 1 min, ambos founders, inglés, ≤100 MB
- [ ] Demo — ≤3 min, ≤100 MB, sin datos de clientes reales
- [ ] Workspace demo con credenciales si se entrega link de producto

### Diferencias con el borrador existente
El borrador incluye una pregunta opcional de "attach a coding agent session" que **no aparece
en este formulario**. Puede que YC la haya quitado o que aparezca más adelante en el flujo —
verificar en el formulario real antes de asumir que hay que prepararla.
